CUSTOMERS MISSING AFTER DEPLOYMENT - SAFE CHECK

1. Open Customers & Machines in V214.
2. If the page says records are hidden by filters, click Clear filters.
3. If it says customers are in Recycle Bin, restore from Recycle Bin.
4. If it says the connected database contains 0 customer records:
   - STOP adding replacement customers.
   - In Render, open the existing BELM web service.
   - Check Environment > DATABASE_URL.
   - Confirm it points to the original BELM PostgreSQL database used before the deployment.
   - Do not create a new Blueprint/database for an update.
5. After reconnecting the original database, redeploy/restart the existing web service and click Refresh customers.

V214 diagnostics do not expose database credentials or database names in the browser.
