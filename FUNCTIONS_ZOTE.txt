BELM PORTAL - CURRENT FUNCTION MAP
==================================

ADMIN
- Customers & Machines
- Customer communication history
- Customer Machine
- Workshop / Engineering / Job Cards
- Procurement / Spare Parts
- General Reports & Analysis
- Manage Customer: edit, reset login + copy credentials, users control,
  delete, forget permanently
- Machine management: edit, delete, forget permanently (admin permissions)
- Billing: invoices, payments, proformas, receipts, company expenses
- Roles/users, checklist templates, suppliers, settings, recycle bin

TECHNICIAN
- Assigned customer landing card
- Communication History before View Machines
- View Machines
- Machine Report
- Check Up + photo evidence + checked report
- Daily checked stamp + automatic Checklist No.
- Service Parts / BELM Store
- Job Card / Workshop
- Activity Status live sync
- No machine edit/delete/forget controls

CUSTOMER
- Own-company dashboard only
- Communication History
- View Machines
- Report / Check Up / Service Parts / Job Card
- Activity Status
- Add/Edit/Delete/Forget machine when customer self-service is allowed
- BELM Service Provider lock for customer machine management
- Workshop, Procurement/Store, General Report Center
- General reports: Checklist, Fuel, Machine Expenses, Maintenance, Operator,
  Technician, Statistics, Store Keeping, Finance
- Customer users/roles and default user limit controls through BELM Admin

SYNC / SAFETY
- Customer/machine data shared by role-specific views from the same database
- Job Card, Technician, Dispatch, Checklist, Proforma/Invoice and expense flows
  retain their existing database-backed synchronization
- Invoice/Proforma master templates are preserved
