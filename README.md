# BELM Operations Portal

Production source for the BELM Operations Portal.

## Runtime
- `frontend/` - portal UI and role workspaces
- `backend/` - PHP APIs, migrations and database logic
- `docker/` - Apache/PHP Render startup configuration
- `Dockerfile` - production container
- `render.yaml` - Render service/database blueprint

## Commercial master templates
The approved immutable BELM commercial masters are:
- `backend/templates/BELM_DIGITAL_PROFORMA_MASTER_V2.pdf`
- `backend/templates/BELM_DIGITAL_INVOICE_MASTER_V2.pdf`

Do not casually delete, rename, replace, optimize, recompress, or edit these PDF masters. `backend/templates/MASTER_TEMPLATES.sha256` pins the approved bytes.

Runtime Proforma/Invoice PDFs are generated by `backend/api/commercial_master_pdf_helper.php`. The renderer uses live customer/items/totals while preserving the approved BELM master layout. Bank QR codes are generated dynamically with each document reference; reference QR images in `backend/assets/commercial_master/` are retained only as source/visual references.

## CI
- `validate.yml` checks PHP syntax, JavaScript syntax and local static asset references.
- `export-zip.yml` creates a short-lived source export artifact from `main`.

Temporary release patches, base64 transport chunks, materialization staging files, per-dashboard development READMEs, and obsolete live-marker text files must not be committed to `main`.
