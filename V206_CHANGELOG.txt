BELM PORTAL V206 - OPERATOR MACHINE-CARD-ONLY ROLE

- Customer Role Manager Operator is now a machine-card-only workspace.
- Operator dashboard hides account Activity Overview, More Tools, BELM messages/proformas/announcements, and the account-wide service-request table.
- Operator starts every action from the relevant machine card.
- Role Manager Dashboard Access controls which machine-card functions appear.
- Operator default preset remains Fuel Usage + Operator Reports + Report Problem.
- Customer Admin may additionally grant Machine Expenses, Request BELM Support, Check Up, or Breakdown Process.
- Store, Management Email and +USER/Role Manager are never valid Operator permissions.
- Backend enforces the same restriction for legacy Operator accounts and direct API attempts.
- No database migration required.
