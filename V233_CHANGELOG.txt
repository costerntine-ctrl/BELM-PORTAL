BELM PORTAL V233 - MAINTENANCE PROCESS: RENAME + BELM ADMIN ACCESS

1. The per-machine quick-action button on the Customer Dashboard
   ("Breakdown Process" on each machine card) is now labeled
   "Maintenance Process", matching the MORE TOOLS button renamed in
   V228. (Same link/destination, only the label changed.)

2. BELM Admin can now use it too. On the Customers Manager (admin
   side), each machine card in the "Machines" list now shows a
   "Maintenance Process" button that opens Breakdown Workflow filtered
   to that machine (actor=admin) - same page the customer uses. It
   only appears when BELM is the active Service Provider for that
   customer (i.e. the customer is not in Self-Service / Customer
   Maintenance Team mode), since BELM has nothing to manage there
   otherwise.

- Browser/PWA cache bumped to V233.
- No database migration required.
