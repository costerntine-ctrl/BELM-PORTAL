BELM PORTAL V234 - GENERAL ANALYSIS (CUSTOMER DASHBOARD)

- Added a "General Analysis" button in MORE TOOLS, next to Management
  Email. Opens a full, organized breakdown dialog using the same data
  already powering the dashboard's Action Center summary
  (/api/customer-portal/analysis), with clear sections:
  - FLEET OVERVIEW: total machines, Green/Yellow/Red counts, due for
    service count.
  - FINANCIALS: machine expenses total, fuel cost total, Petty Cash
    (topped up / used / balance), invoices (total / outstanding).
  - SERVICE & SUPPORT: total/open service requests, checklist reports
    count, containers handled.
  - PER-MACHINE BREAKDOWN: a table listing every machine with its
    status, open requests, report count, expenses, and service level -
    so the customer can see each machine's own activity at a glance.
- Translated (English default / Kiswahili) like the rest of the
  dashboard overlay.
- Browser/PWA cache bumped to V234.
- No database migration required (reuses the existing analysis
  endpoint - no backend changes).
