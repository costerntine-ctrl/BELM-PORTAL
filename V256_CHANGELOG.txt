BELM PORTAL V256 - FIX: ADMIN LOGIN HAD NO INSTALLABLE APP

ROOT CAUSE
- V249 added a proper web app manifest and Apple PWA meta tags to
  frontend/index.html (the shared shell that serves /admin/login,
  /portal/dashboard, and /tech).
- A manifest alone isn't enough for a browser to offer "Install app" /
  "Add to Home screen" as a real standalone app - an active service
  worker is also required. The service worker registration code only
  ever existed inside customer-app.js, a script loaded from the older,
  separate customer-app.html page - never from index.html.
- Net effect: /admin/login (and, less obviously, /portal/dashboard and
  /tech too) had the manifest and icons ready, but no service worker
  ever registered there, so the browser never considered it
  installable - "Haina app."

FIXED
- Added the same service worker registration to frontend/index.html
  directly, so /admin/login, /portal/dashboard, and /tech all properly
  register belm-sw.js and become installable as a real app - not just
  a bookmark shortcut.

- Browser/PWA cache bumped to V256.
- No database migration required.
