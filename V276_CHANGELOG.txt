BELM PORTAL V276 - "BACK" NOW WORKS PROPERLY FOR EVERY DIALOG

Requested: make sure Back works correctly for every function you open
(View Machines -> Report, Check Up, Expense Receipts, Service Parts,
Edit, Delete, and every other dialog on this page - Message Customer,
Edit customer, etc.).

ROOT CAUSE
- Native <dialog> popups (used for all 11+ of these on this page)
  don't touch browser history on their own. Pressing the phone's
  system Back gesture, or the browser's own Back button, while one was
  open would leave the whole Customers Manager page instead of just
  closing that dialog - easy to lose your place, especially on mobile
  where "back" is the natural way to dismiss something.

FIXED - one shared mechanism covers every dialog on this page
- Opening ANY dialog (Report, Check Up, Expense Receipts, Service
  Parts, Edit, Delete confirm, Message Customer, and all the rest) now
  adds one step to the browser history.
- Pressing Back (or the phone's back gesture) while a dialog is open
  now closes that dialog instead of leaving the page.
- Closing a dialog normally - Cancel, the × button, ESC, or a
  successful save - cleans up that same history step automatically,
  so Back afterwards goes exactly where it should with no leftover
  empty step either way.
- Built once, generically, at the top of the file - it did not need to
  be wired into each of the 11 dialogs individually, and it will
  automatically cover any dialog added to this page later too.

- Browser/PWA cache bumped to V276.
- No database migration required.
