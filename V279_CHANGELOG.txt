BELM PORTAL V279 - SIDEBAR SEARCH

The admin sidebar has grown to 17+ items across 4 sections
(Operations, Maintenance, Parts & Procurement, Finance, Administration)
- added a search box right under the BELM Admin card so you can jump
straight to one instead of scanning/expanding every group.

- Type any part of a menu item's name (e.g. "spare", "billing",
  "recycle") - matching items stay visible, everything else (both
  individual links and whole sections with zero matches) hides
  instantly as you type.
- A section with at least one match opens automatically so the result
  is actually visible, even if you had it collapsed before.
- An × button appears once you've typed something, to clear the
  search in one tap - this restores every section to exactly how it
  was open/closed before you started searching (not just "everything
  expanded").
- Shared across every admin page (17 standalone admin pages, plus the
  Breakdown Workflow page when opened by BELM Admin) since it's built
  once into the shared admin-sidebar.js/.css files already used
  everywhere.

- Browser/PWA cache bumped to V279.
- No database migration required.
