BELM Portal V295 - Machine Spare List / Customer Store / Expenses Approval

1. Machine Spare List
- Added Save Spare List on Customer Service / Spare Request page.
- The saved list is persistent per customer machine and restores after reload/login.
- Each row can be selected/deselected for the next action.

2. Customer Store balance sync
- Added Sync Store Balance.
- Matching prioritizes exact part number; exact spare description is a fallback.
- Each spare shows IN STORE, STORE SHORTAGE, or NOT IN CUSTOMER STORE.
- BELM internal inventory remains private and is never exposed by this sync.

3. Procurement CSV
- Added Download Selected CSV.
- CSV includes machine, part number, description, requested qty, Customer Store available qty, procurement qty, unit, and recommended action.
- Selected items already available in Customer Store remain visible in the CSV with procurement qty 0.

4. Store -> Expenses Approval
- Added Send Selected to Expenses Approval.
- Available Customer Store quantity can enter PENDING APPROVAL; if the Store has only part of the requested quantity, the available portion goes to approval and only the shortage remains for procurement/BELM supply.
- Not-in-store items are returned as procurement/BELM-supply requirements.
- Duplicate list rows resolving to the same Store item are grouped before approval.

5. Approval / deduction control
- Added Customer Store -> Expenses Approval panel in Machine Expenses.
- Customer Owner, Admin, or Accounts can Approve/Reject (subject to Role Manager access).
- Approval is atomic: Customer Store balance is deducted, Store ISSUE audit is written, and Machine Expense is created together.
- If stock changes and becomes insufficient before approval, approval is blocked and stock never goes negative.
- Rejection does not change Store balance.

6. Spare request reliability
- Corrected customer BELM spare-request endpoint/payload so selected spare requests actually save through customer authentication.
