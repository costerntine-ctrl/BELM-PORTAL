BELM Portal V299 - Session Stability Fix

- Added rolling 30-day authenticated sessions for staff, customers and operators.
- Added POST /api/auth/refresh with live database account validation.
- Global fetch wrapper refreshes and retries a stale token once before any page can treat a 401 as logout.
- Pages that captured an older token at load automatically use the latest refreshed token.
- A valid refreshed session that is forbidden from one endpoint no longer causes whole-account logout.
- Technician assignment/provider changes no longer delete the Technician token or auto-redirect to login.
- Explicit Logout buttons and true disabled/deleted/expired account handling remain unchanged.
- Theme manager and service-worker cache versions bumped so the fix deploys immediately.
