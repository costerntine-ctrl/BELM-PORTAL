BELM PORTAL V377 — ADMIN MACHINE MANAGEMENT ACTIONS

Scope: BELM Admin only. Customer portal/View Your Machine is unchanged.

BELM Admin > Customers & Machines > View Your Machine:
- Keeps the four operational buttons on one row: Report, Check Up, Service Parts, Job Card.
- Activity Status is balanced into a compact full-width row so the label and selector fit the fixed customer-card-sized machine card cleanly.
- Adds a second row directly underneath:
  1. Edit Machine — reuses the existing edit-machine dialog/function.
  2. Delete Machine — reuses the existing soft-delete / Recycle Bin function.
  3. Forget Permanently — Super Admin only; permanently removes the selected machine and its machine-owned history, without deleting the customer or other machines.

Safety / sync:
- Permanent machine deletion mirrors the established Danger Zone hard-delete cleanup.
- Independent billing/service records are detached from the machine rather than deleting the customer history.
- Backend requires Super Admin for permanent machine deletion.
- Customer-facing portal files are not modified by V377.
