BELM PORTAL V415 - WORKSHOP ANALYSIS INSIDE TECHNICAL DEP

- Added Workshop Analysis as a first-class section in BELM Admin > TECHNICAL DEP.
- TECHNICAL DEP navigation now contains: Job Card, Workshop Analysis, Tools, Technicians, Engineers.
- Workshop Analysis reuses the live Breakdown Workflow / Digital Job Card analytics so there is no duplicate data source.
- Included the requested operational blocks:
  * Daily / Monthly period and report date
  * New breakdowns
  * Jobs completed
  * Delayed now
  * Waiting parts/process
  * First-time fix
  * Average repair time
  * Where work is waiting now
  * Technician results for selected period
  * Workshop control
  * Repeat / common faults
  * Technician Performance cards
- Analysis opens embedded inside TECHNICAL DEP without showing Dispatch, live queue, or case-detail panels.
- Existing Job Card permissions are reused for Workshop Analysis so current Workshop Manager access remains compatible.
