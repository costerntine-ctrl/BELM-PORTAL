BELM PORTAL V425 - BREAKDOWN REPORTED TIME + MACHINE HOURS

Live Breakdown Queue cards now show:
- Reported: source report date/time
- Machine Hrs: hour-meter reading at/just before the report time

Source behavior:
- RED/DON'T OPERATE Checklist: uses that checklist's exact hour-meter reading and submitted time.
- Operator Reported: uses operator report time and latest checklist hours recorded at or before that time.
- Customer/Manual Breakdown: uses case opened time and latest checklist hours at or before that time.
- Official Job/Support source: uses source creation time where available and latest checklist hours at or before it.

This prevents later checklists from changing the historical machine-hours context shown on an older breakdown.
