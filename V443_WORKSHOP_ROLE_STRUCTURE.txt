V443 - Workshop Role Structure

Customer Dashboard and BELM Customer View now open a dedicated Workshop role hub.

Workshop roles:
1. Workshop Manager - Job Cards, assignment/reassignment, instructions, workload, testing/review, Workshop Analysis.
2. Store Keeper - Customer spare stock, workshop tools, Tool Issue Documents and Tool Return Documents.
3. Technicians - Mechanic / Electrical / Mechatronics repair specializations; receive work from Workshop Manager.

Customer Store Keeper Tool Register:
- Tool Issue document number TI-DD-MM-YY-01...
- Optional Job Card number
- Technician
- Tool name / Tool ID
- Quantity
- Condition out
- Expected return
- Issued by/date
- Return date / condition in / received by
- Status: OUT WITH TECHNICIAN or RETURNED

BELM Customer View uses the same role structure but keeps BELM and customer-owned permissions separated.
