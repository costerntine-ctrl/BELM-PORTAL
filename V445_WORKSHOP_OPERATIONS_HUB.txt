V445 - Workshop Operations Hub

Customer Dashboard and BELM Customer View keep the approved dashboard card unchanged. Clicking Workshop now opens one operational hub with six connected roles/functions:
1. Workshop Manager - Job Cards, assign/reassign, instructions, workload, testing/review, Workshop Analysis.
2. Technician - assigned work, diagnosis/repair, tool/spare requests, progress and Technician Report.
3. Machine Operator - machine condition, operator report, problem reporting, fuel/hours and daily feedback.
4. Store Keeper / Tools - customer spare stock plus Tool Issue and Tool Return Documents.
5. Procurement - spare request queue, Store check, shortage/purchasing/order and Parts Ready status.
6. Management / Administration - Role Manager, approvals, petty cash/workshop funding and oversight.

Flow:
Operator / Machine Report -> Workshop Manager -> Job Card -> Technician -> Store / Tools -> Procurement if shortage -> Repair & Testing -> Manager Review -> Administration / Close.

BELM Customer View shows the same six-role structure but routes BELM-side actions only to BELM pages and keeps customer-owned roles separated.

Bug fix:
- Customer Role Manager backend now accepts the Technician role (the UI already offered it, but the API allow-list omitted it).
- Added an anchor ID for the Machine Operator roster section so Workshop can open the correct management area.

Responsive layout:
- Desktop: 3 cards per row.
- Tablet/small laptop: 2 cards per row.
- Phone: 1 card per row with stacked actions.
