V450 - Removed the redundant "Customers Overview" hero + metrics

Now that Customers & Machines is branded TECHNICAL DEP overall (see
V446), the old "Fleet Status / Customers Overview" hero and its four
metric cards (Customers / Machines / Green machines / Need attention)
sat awkwardly below the TECHNICAL DEP hero/nav/Job Cards/etc, repeating
information already visible on the customer cards themselves.

Removed: the "Fleet Status" hero section and the "metrics" section.
Kept, unchanged: the alert banner, the Machine Type <-> Checklist
Template Sync panel (a real function, not decorative), the search/filter
toolbar, and the customer card grid itself - all functions of Customers &
Machines remain exactly as they were.

Result: opening TECHNICAL DEP now shows the TECHNICAL DEP hero/nav/Job
Cards/Workshop Analysis/Tools/Overview grid first, and scrolling down
reaches the search/filter bar and customer cards directly - no redundant
second "Customers Overview" header in between.

manager.js's updateMetrics() now guards each element with a null check
instead of a bare document.getElementById(...).textContent assignment,
since those four elements no longer exist in the page - this keeps the
function harmless if the cards are ever brought back later, and prevents
a runtime error that would otherwise have interrupted the rest of the
script from running.
