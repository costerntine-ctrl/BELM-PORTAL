V451 - Sidebar text in ALL CAPITAL LETTERS

frontend/admin-sidebar.css: added
  .belm-admin-sidebar { text-transform: uppercase; }
covering every visible sidebar text: brand ("BELM GENERAL TECH" /
"Operations & Service Portal"), the logged-in user's name and role
("BELM Admin" / "Super Admin"), every navigation link label (Overview,
BELM Staff Access, TECHNICAL DEP, PORTAL-CWM, etc.), and the footer
(Light/Dark mode toggle, Log out securely).

The sidebar's search box ("Search menu...") is explicitly excluded
(text-transform: none on its input/placeholder) so what the person types
or reads there isn't forced into capitals.

This is a pure CSS change - no label strings, IDs, or JS logic were
touched, so search/filter matching, active-link detection, and
permission checks all keep working exactly as before.
