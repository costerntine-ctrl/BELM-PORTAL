BELM PORTAL V453 - SYSTEM STARTING PASSWORD + SELF-SERVICE PASSWORD RECOVERY

Customer Workshop Role Manager credential policy:
- When Customer Admin/Owner creates a Workshop Manager, Store Keeper, Procurement, Accounts, Operator or Customer Technician, the server generates a secure starting password automatically.
- The starting password is returned only in the create response and displayed in a one-time credential dialog with Email, Starting Password and Login Link.
- Role Manager does not expose password editing/reset after account creation.
- After creation, the user uses Forgot Password on the login page. A 6-digit OTP is sent to the user's registered email and the user sets a new password.
- Edit User continues to manage profile, role, permissions and active/inactive status only.
- Existing accounts/passwords are not changed by this version.
