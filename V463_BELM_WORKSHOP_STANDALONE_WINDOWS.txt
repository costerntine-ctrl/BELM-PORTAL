V463 - BELM WORKSHOP STANDALONE WORKSPACE WINDOWS

Goal
- BELM WORKSHOP remains its own technical workspace.
- Pressing Job Card must NOT navigate the user back into the BELM Admin main dashboard.
- Workshop modules share the same live backend data so Job Cards, assignments, reports, spare requests and status stay synchronized.

BELM WORKSHOP
- All six V461 placeholder buttons are now real Workshop functions.
- Each function opens in a large responsive Workshop window (dialog + same-origin iframe), keeping /belm-workshop/ as the parent workspace.
- The window has Sync / Refresh and Close controls.
- Hash routes continue to work for existing links:
  #job-cards
  #workshop-analysis
  #store-spares
  #tool-issue-documents
  #manage-technicians
  #assigned-work

Open Job Cards
- Opens /breakdown-workflow/?actor=admin&embed=1&view=job-cards inside BELM WORKSHOP.
- Uses the existing Digital Job Card / Breakdown Workflow backend; no duplicate Job Card database.
- Existing machine-card links such as /belm-workshop/?machine=<id>#job-cards now auto-open this internal Job Card window and preserve the machine filter.
- Full Job Card view includes live source synchronization, dispatch, Job Card process, live breakdown queue/detail and Technician workload. Workshop Analysis stays in its own window.

Workshop Analysis
- Opens the existing Digital Job Card analysis in an internal Workshop window (view=analysis).
- Uses the same live Job Card data.

Store & Spares
- Opens BELM Spare Parts Manager in an internal Workshop window.
- Added embed mode so the Store page does not show a duplicate Admin sidebar/header inside the Workshop window.

Tool Issue Documents
- New BELM-owned workshop Tool Issue / Return register, separate from Customer Workshop tools.
- Tool Issue Document records: document number, optional live Job Card, Technician, tool, asset ID, quantity, condition out, expected return, issue note, return date, condition in, received by and return note.
- Linked to BELM Technicians and live Digital Job Card numbers.
- New table: belm_workshop_tool_issues.
- New Engineering API actions: workshop-tool-options, workshop-tool-issues, workshop-tool-return.

Manage Technicians
- Opens BELM Staff Access filtered to Technician inside the Workshop window.
- Embed mode prevents duplicate navigation chrome.
- Existing multi-role BELM staff support remains intact.

View Assigned Work
- New internal view of the Digital Job Card process + Technician live workload.
- Auto-refreshes live assigned work every 15 seconds while visible.

Permissions
- BELM WORKSHOP can now be reached by BELM roles with roles, job-cards, service-requests, or spare-parts access.
- Each internal module still checks its own required permission before opening.

QA
- Modified JavaScript passes node --check.
- All backend PHP files pass php -l.
- Existing /belm-workshop/#job-cards and /belm-workshop/#workshop-analysis links remain compatible and now open working internal windows instead of dead anchors.
