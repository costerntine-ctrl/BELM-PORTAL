BELM PORTAL V472 - SYNC & INTEGRATION AUDIT
Date: 24 Aug 2026
Base: V471 PORTAL-BELM WM + PORTAL-CWM

FIXED BUGS
1. TECHNICAL DEP / Customers Manager runtime script
   - Restored /customers-manager/manager.js script include.
   - V471 had a malformed/unclosed regression comment that could prevent the page logic from loading.

2. Nested Workshop sidebar
   - /portal-cwm/ now uses the same compact nested sidebar as /customers-manager/ and /belm-workshop/.
   - Customer Overview, PORTAL-BELM WM and PORTAL-CWM remain directly switchable.

3. PORTAL-CWM Technician count sync
   - Customer Technicians are stored in users (is_customer_managed=1), not customer_users.
   - CWM overview now counts Technicians from the same source used by Customer Workshop.
   - Workshop Manager / Store Keeper / Operator counts remain customer_users based.

4. PORTAL-CWM live ownership/status visibility
   - Customer cards now show CUSTOMER WORKSHOP vs BELM SERVICE ownership.
   - Cards show live WM / STORE / TECH / OP counts from the authoritative records.

5. BELM Workshop Tool Issue / Job Card boundary
   - BELM Tool Issue Job Card dropdown no longer exposes private internal Job Cards of a self-managed customer.
   - Such Job Cards are available to BELM only when they are official SERVICE_REQUEST / BELM Support work.
   - The same validation is enforced server-side on save, not only in the dropdown.

6. BELM Workshop Petty Cash token/sync bug
   - The BELM Workshop button no longer opens the customer-token-only Petty Cash page.
   - Added /belm-workshop/petty-cash/ using BELM admin authentication.
   - It reads the same usage_logs and petty_cash_topups records used by PORTAL-CWM.
   - BELM top-ups therefore appear in the customer's Petty Cash balance; customer expenses appear in BELM Workshop view.
   - Customer financial privacy rules are still enforced.

7. Canonical login cleanup
   - Standalone Customer Workshop / Customer Users / Customer Job Card fallback redirects now point directly to /login.
   - Apache legacy redirects remain in place for old bookmarks.

SYNC CONTRACT VERIFIED IN CODE
- Customer identity/mode switches: customers table.
- BELM Service ON/OFF: customers.is_machinery_admin (historical inverse flag).
- PORTAL-CWM ON/OFF: customers.workshop_module_active.
- Portal Lock/Unlock: customers.is_active.
- Machines: machines.customer_id.
- Job Card process: breakdown_cases + digital_job_cards shared by BELM/customer workflow with ownership filters.
- Customer-managed Technicians: users.assigned_customer_id + is_customer_managed=1.
- Customer role users: customer_users scoped by customer_id.
- Customer Store/Tools remain customer-owned; BELM Store/Tools remain separate.
- Petty Cash: usage_logs(category PETTY_CASH) + petty_cash_topups shared account records.

INTENTIONAL / NOT CHANGED
- The 8 numbered buttons on PORTAL-CWM customer cards are still disabled placeholders because their business functions have not yet been assigned.
- No database schema/table changes were required in V472.

QA PERFORMED
- PHP syntax check across backend.
- JavaScript syntax check across frontend.
- HTML comment-balance and duplicate-ID checks on relevant pages.
- Static route/file-reference check on relevant portal modules.
- ZIP integrity check before release.

The code-level routing, ownership, data-source and authentication contracts were checked; after deployment, use real test accounts for one BELM-managed customer and one self-managed PORTAL-CWM customer to verify live database data end-to-end.
