V474 SESSION PERSISTENCE FIX

- Session refresh is server-authoritative and tolerant of device clock skew.
- Network/Render wake-up failures no longer convert into logout.
- Admin permission guard no longer deletes a valid login token.
- Service worker no longer falls back to the login shell on authenticated navigation failure.
- Sessions are revalidated on focus, online, pageshow and visibility restore.
- JWT lifetime remains 30 days with rolling renewal; account disable/delete still invalidates access.
- Authenticated pages install session protection before page/API logic runs.
- /login resumes a server-validated active session instead of requesting the password again after an accidental redirect.
