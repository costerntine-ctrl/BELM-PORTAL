BELM PORTAL V491 - CUSTOMER REGISTRATION SYNC

- Manual Customer Registration now explicitly selects TECHNICAL DEP or PORTAL-CWM.
- Public registration approval and manual registration use the same backend mode rules.
- New customer registration explicitly sets BELM Service / Workshop Module flags instead of relying on DB defaults.
- Registration response verifies the shared customer/company_id is immediately visible to Customer Overview, WM Customer Overview, Customer Dashboard, machine scoping, Manage Users, Procurement and Reports.
- PORTAL-CWM registrations start BELM OFF + Workshop Module ON.
- TECHNICAL DEP registrations start BELM Service ON; Workshop Module remains BELM-controlled as before.
- Customer credentials dialog shows Registration Mode and synchronization destinations.
- Customer Overview refreshes automatically across tabs when a new customer is registered/approved.
- No duplicate customer table or copied customer record was added; all destinations use the same customers.id.

- TECHNICAL DEP customer Owner/Admin/Workshop Manager now lands on the same PORTAL-CWM home with BELM Service ON; Store/Tool controls remain gated when the paid Workshop Module is OFF.
- PORTAL-CWM shell therefore remains the customer home in both service modes; the BELM switch controls responsibility rather than changing dashboards.
