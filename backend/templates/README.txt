BELM COMMERCIAL MASTER TEMPLATES - V345

These two PDF files are the approved immutable visual masters supplied by BELM:
- BELM_DIGITAL_PROFORMA_MASTER_V2.pdf
- BELM_DIGITAL_INVOICE_MASTER_V2.pdf

Do not delete, rename, replace, optimize, recompress, or edit these files casually.
MASTER_TEMPLATES.sha256 pins the exact approved bytes.

Runtime Proforma/Invoice PDFs are generated by:
backend/api/commercial_master_pdf_helper.php

The runtime renderer uses live customer/items/totals but preserves the approved
master layout: BELM header, website QR, Bill To / Document Details blocks,
items table, totals, bank-detail QR cards, trading terms, and website footer.

Bank QR codes are generated dynamically with each document reference. Docker
installs qrencode for this purpose. The reference QR PNGs in
backend/assets/commercial_master are kept only as visual/source references.
