BELM PORTAL V207 - TECHNICIAN FULL CUSTOMER CONTROL

1. Customer Administration can now grant a customer-managed Technician either selected Dashboard Access or Full Customer Control from Role Manager.
2. Operator remains machine-card-only; Technician is not restricted to card-only mode.
3. Technician keeps the dedicated Technician Workspace for Job Cards, diagnostics and checklists.
4. When dashboard access is granted, the Technician Workspace shows a Customer Dashboard shortcut. Full-control Technicians see “Customer Dashboard - Full Control”.
5. The same Technician login/token can securely open customer dashboard APIs only for its assigned customer. BELM internal Admin/Inventory access is never inherited.
6. Technician permissions are stored separately on users.customer_permissions. Existing customer-managed Technicians default to no customer-dashboard access until Administration grants it.
7. Administration can edit Technician name, email, phone, active status and dashboard permissions without changing the password. Password recovery remains Forgot Password + OTP.
8. Full Control may include Store, Expenses, Fuel, Workflow, Check Up, Management Email and +USER; selective access can be granted instead.
9. Role-aware customer team alerts now also include customer-managed Technicians when their granted permissions match the alert.
10. BELM Service Provider ON still pauses customer-managed Technician access automatically; other customer roles remain active.

DEPLOYMENT: Run backend/schema.sql so users.customer_permissions is available.
