BELM PORTAL V214 - CUSTOMER VISIBILITY & DATA DIAGNOSTIC

Fixes:
- Customers Manager no longer says "Register a customer" when registered customers are merely hidden by an old search/filter.
- Added Clear filters and Refresh customers controls.
- Added admin-only /api/customers/diagnostics endpoint with non-sensitive record counts.
- If 0 visible customers are returned, the page distinguishes:
  1) customer records hidden by filters,
  2) customers in Recycle Bin,
  3) connected PostgreSQL database contains no customer records,
  4) permission/API failure.
- Bumped Customers Manager JS cache key from the old V194 key to V214.

IMPORTANT DATA RECOVERY NOTE
If the page reports that the connected database contains 0 customer records, the UI is not hiding them. Check the Render web service DATABASE_URL and reconnect it to the original BELM PostgreSQL database. Do not recreate customer records until the original database connection has been checked.

No database migration is required for V214.
