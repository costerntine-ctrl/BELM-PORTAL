BELM PORTAL V227 - CUSTOMER DASHBOARD: ONE UNIFIED OVERVIEW CARD

- Status (Action Required / All Clear), Petty Cash, and Breakdown
  Process are no longer three separate floating cards on the Customer
  Dashboard. They now live as sections inside ONE card (single border,
  single shadow, single gradient stripe), separated by thin dividers -
  regardless of how many machines the customer has.
- Petty Cash and Breakdown Process sit side by side inside that one
  card on tablet/desktop widths; below 640px they stack in a single
  column so nothing gets cramped on small phones.
- Business Snapshot and Machines Needing Action remain inside the same
  card, unchanged in behavior.
- MORE TOOLS stays a separate card below (it's an action panel, not a
  "read" summary, so it wasn't part of this consolidation).
- Browser/PWA cache bumped to V227.
- No database migration required.
