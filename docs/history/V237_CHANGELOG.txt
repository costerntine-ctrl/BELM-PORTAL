BELM PORTAL V237 - CHECK-UP REPORT: TECHNICIAN NAME FIX + FULL SYNC AUDIT

ROOT CAUSE FOUND
- The BELM Admin "Check Up" form (Customers Manager -> View Machines ->
  Check Up) had no field to record which Technician/Inspector actually
  performed the check-up. Every check-up submitted by an Admin/staff
  account (not logged in as a Technician) was silently attributed to
  that Admin's own name instead of the technician who did the physical
  inspection - so the technician never appeared on the report/PDF.
  (A real Technician logging into their own /tech account was never
  affected - their name is always locked to their own account.)

FIXED
- Added a "Technician / Inspector" name field to the admin Check Up
  form. Leave it blank and the report still falls back to your own
  (Admin) name, exactly as before - fill it in and the report/PDF
  correctly shows the technician who actually did the check.
