BELM PORTAL V252 - CHECKLIST TEMPLATE: UPLOAD CSV (SECOND WAY TO BUILD ITEMS)

- Added a "⇪ Upload CSV" button next to "+ Add item" in the Checklist
  Template editor (Edit template / New template).
- This is a SECOND way to build the same items list - it doesn't
  bypass anything. Uploading a CSV parses each row into a checklist
  item (label, input type, safety color, required, dropdown values)
  and appends it into the same editable list "+ Add item" builds one
  row at a time. You can still review, edit, add, or remove any item
  afterward exactly as before, and nothing is saved to the template
  until you click "Save template" - same as manual entry.
- CSV format (a small help line is shown right under the buttons):
  Item Label, Input Type, Default Safety, Required, Dropdown Values
  - Input Type: TEXT, NUMBER, YES_NO, DROPDOWN, DATE, or PHOTO
  - Default Safety: NONE, GREEN, YELLOW, or RED (ignored for PHOTO)
  - Required: YES or NO
  - Dropdown Values (only for DROPDOWN): Value:COLOR pairs separated
    by | — e.g. Normal:GREEN|Low:YELLOW|Contaminated:RED
  - For YES_NO, put YES:GREEN|NO:RED in Dropdown Values to say which
    answer is the safe one.
  - A header row is optional - detected automatically and skipped if
    present.
- Bad or unrecognized rows don't block the good ones: an unknown input
  type falls back to TEXT, a DROPDOWN row with no valid Value:COLOR
  pairs is still added (empty, ready to fill in by hand), and a
  summary of any warnings is shown so nothing silently goes missing.

- Browser/PWA cache bumped to V252.
- No database migration required.
