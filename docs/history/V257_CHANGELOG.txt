BELM PORTAL V257 - BILLING: CUSTOMER DROPDOWN NOW RETRIES / STAYS SYNCED

ROOT CAUSE
- The Billing page only ever fetched the customer list ONCE, when the
  page itself first loaded. If that single attempt failed (network
  blip, timing), or a new customer was added to Customers Manager
  after Billing was already open, the "New invoice" / "New proforma"
  Customer dropdown stayed stuck on just "Select customer…" for the
  rest of the session - reopening the dialog never tried again. (Spare
  Parts, by contrast, already had a retry-on-open pattern, which is
  why that dropdown worked fine in the same screenshot.)

FIXED
- New invoice and New proforma dialogs now retry loading the customer
  list every time they're opened, IF the list is currently empty -
  matching how Spare Parts already behaves. A customer created
  moments earlier now shows up the next time you open New invoice/
  proforma, without needing a full page reload. If the retry itself
  fails, the same clear "Customer list could not load: ..." warning
  is shown as before.

- Browser/PWA cache bumped to V257.
- No database migration required.
