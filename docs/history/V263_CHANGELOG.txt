BELM PORTAL V263 - HID "SEND TO BELM" BUTTON FROM BELM'S OWN DASHBOARD

ROOT CAUSE
- The "→ Send to BELM instead (Request Support)" button (V243) was
  added to the shared Generate Digital Job Card dialog with no
  visibility check - since that same dialog is used by Customers,
  BELM Admin/Workshop, and Technicians alike, the button showed up
  everywhere, including on BELM's own internal Admin/Workshop
  dashboard - nonsensical there, since BELM Admin viewing it IS BELM;
  there's no one else to "send to."

FIXED
- The button (and its helper text) now only shows when the dialog is
  opened by an actual Customer actor. It stays hidden for BELM Admin/
  Workshop and Technician views of the same dialog.

- Browser/PWA cache bumped to V263.
- No database migration required.
