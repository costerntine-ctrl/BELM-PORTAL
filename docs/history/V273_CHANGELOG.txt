BELM PORTAL V273 - JOB CARD REPORTS + DAILY REPORT TABS (WITH PDF EXPORT)

Added two new tabs to the Check Up dialog (Customer Dashboard, per
machine), next to Checklist ya Siku / Checked Reports:

1. JOB CARD REPORTS - every Digital Job Card for this machine
2. DAILY REPORT - every submitted checklist/check-up report for this
   machine, organized as its own history view

BOTH TABS INCLUDE
- A date filter: Specific date, Month, Year, Custom range, or All
  time - pick the mode, fill in the field(s) shown, click Apply.
- A "⭳ Download PDF" button that generates one combined PDF for
  whatever period is currently selected (not one file per record).

PERMANENCE - as requested
- Nothing here can be hidden or deleted from this screen - it's a
  read/export view only. Job Cards and Checklist Reports already stay
  in the database permanently by design (the only place records are
  ever actually removed is the "Forget permanently" flow audited in
  V266, which only runs when BELM Admin deliberately erases an entire
  customer account - not from anything on this page). If a period
  shows no results, the empty-state message says so explicitly rather
  than leaving any doubt about whether something was lost.

BACKEND
- New: GET /api/customer-portal/machines/{id}/job-cards (with
  ?from=&to=), GET .../job-cards-pdf, GET .../reports-pdf - all
  customer-authenticated and scoped to that customer's own machine,
  reusing the existing raw-PDF table generator already used elsewhere
  in the portal (same style as Invoices/Expenses exports).
- Date filters accept a full date (2026-08-16), a month (2026-08), or
  a year (2026) and resolve to the correct whole period automatically.

- Browser/PWA cache bumped to V273.
- No database migration required.
