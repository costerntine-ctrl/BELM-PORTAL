BELM Portal V290 - Machine Report Center

Customer Fleet > Machine > Report now opens one Report Center with:
- Checklist Report
- Job Card Report
- Daily Report

Reporting controls:
- All time
- Specific Date
- Month
- Year
- View Reports
- Download Report for the selected period

Checklist Report:
- Lists saved checklist/check-up reports for the selected period.
- View Report opens the saved checked report details.
- Download Report downloads the individual watermarked checklist PDF.

Job Card Report:
- Lists Digital Job Cards for the selected period.
- View Report shows status, technician, fault/job, diagnosis, work done, test result, completion note and repeat/rework flag.
- Download Report downloads the individual watermarked Job Card PDF.
- Selected-period Download Report exports the Job Card history PDF.

Daily Report:
- Groups saved checklist activity by Tanzania calendar date.
- View Report shows that day's saved machine-report activity.
- Download Report exports that day's watermarked summary PDF.
- Date/Month/Year Download Report exports the selected reporting period.

Security / compatibility:
- Existing V288 Customer privacy enforcement is preserved for maintenance records.
- Existing V289 friendly BELM/customer links and customer-name labels are preserved.
- Existing technician/checklist PDF watermark behavior is preserved.
