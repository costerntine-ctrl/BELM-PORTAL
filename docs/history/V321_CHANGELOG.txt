BELM Operations Platform V321

REGISTERED USERS PASSWORD RESET
- Added Reset Password action directly to Access Applications > Registered users.
- Reset generates a new temporary password and recovery code; old passwords are never revealed.
- After reset, Super Admin sees user email, one-time temporary password, recovery code and canonical portal login link.
- Added Copy login details, Copy password and Copy login link actions.
- Clarified that all BELM portal accounts use the same canonical /login link; role/customer routing happens after authentication.
- Existing user edit/delete behavior is unchanged.

SECURITY
- Reset still requires the existing BELM edit confirmation control.
- Existing password hashes are not reversible and are never displayed.
