BELM Operations Platform V322

REGISTERED USER ACTIONS FIX
- Fixed Edit, Delete and Reset Password actions in Access Applications > Registered users.
- Registered-user actions no longer depend on a separately configured Edit/Delete PIN.
- Edit and Reset Password now require the signed-in admin's current login password.
- Delete requires the signed-in admin's current login password plus a deletion reason.
- Legacy PIN payloads remain accepted by the backend for compatibility with older cached clients.
- The currently signed-in account cannot delete itself.
- Added a dedicated account-action confirmation dialog and hardened delegated click handling.
- Reset Password still returns the one-time temporary password, recovery code and the shared portal login link.

NO DATABASE MIGRATION REQUIRED.
