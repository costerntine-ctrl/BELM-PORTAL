BELM PORTAL V362 - MY C QUICK ACTION BUTTONS

- Added four quick-action buttons below the selected customer details in MY C.
- Button colors and destinations:
  1. View Your Machine - black - opens Customers & Machines and automatically opens the selected customer's machine list.
  2. Workshop - blue - opens Engineering.
  3. Procurement - green - opens Spare Parts Inventory / procurement area.
  4. General Report - yellow - opens Reports & Analysis.
- Added responsive 4-column / 2-column / 1-column layout for desktop, tablet and mobile.
- Existing MY C customer profile, portal link and copy/open-login functions are unchanged.
