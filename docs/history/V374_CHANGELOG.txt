BELM PORTAL V374 — ADMIN MANAGE CUSTOMER / USERS CONTROL

- BELM Admin only. Customer Dashboard V372 is unchanged.
- Moved Customer user limit control from the page-level settings row into Manage Customer.
- Manage Customer now includes Users Control.
- Users Control shows users currently in use and the current maximum.
- System default remains 3 portal users when customers.user_limit is NULL.
- BELM Admin can increase the limit after a customer requests additional users.
- Existing /customers/:id/user-limit endpoint, Edit confirmation, activity log, permissions and sync logic are reused.
- Reset Login, Edit Customer, Delete and Forget Permanently behavior is unchanged.
- Admin list now includes an accurate active portal-user count (customer users + customer-managed Technicians) for Users Control without exposing hidden team-directory identities.
- The user-limit API now rejects limits lower than the number of active portal users already in use.
