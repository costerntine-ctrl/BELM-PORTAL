BELM PORTAL V387

Scope: Customer -> View Machines only.

- Added Add Machine as the fourth customer machine-management action alongside Edit Machine, Delete Machine and Forget Permanently.
- All four management actions are available only to the customer owner / Company Admin while Customer Self-Service is ON.
- When BELM Service Provider is ON, all four buttons remain visible but are disabled on the Customer side.
- Backend enforces the same provider switch so disabled controls cannot be bypassed by direct API calls.
- Add/Edit keep Machine Type, Model, Serial, Registration, Fleet Number, Brand and Service Kit synchronized with the shared machine record.
- Delete moves the customer machine to Recycle Bin; Forget Permanently removes only that machine and its machine-owned history.
- BELM Admin and BELM Technician interfaces are unchanged.
