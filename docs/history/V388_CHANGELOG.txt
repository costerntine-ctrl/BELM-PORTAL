BELM PORTAL V388

Scope: Customer Dashboard -> General Report.

- Changed the Customer Dashboard General Report button into a report center with 8 report categories:
  1. Checklist Report
  2. Fuel Consumption Report
  3. Machine Expenses Report
  4. Maintenance Report
  5. Operator Report
  6. Technician Report
  7. Statistics Analysis
  8. Store Keeping
- Checklist Report opens a machine selector and completed checklist history, with View and PDF actions.
- Fuel Consumption Report opens the existing Customer Fuel Usage report workspace.
- Machine Expenses Report opens the existing Customer Machine Expenses workspace.
- Maintenance Report opens a machine selector and shows service status plus Job Card history.
- Operator Report opens a machine selector and the existing customer Operator Report history.
- Technician Report opens a machine selector and combines technician checklist activity with Job Card activity.
- Statistics Analysis reuses the existing fleet/account General Analysis data and calculations.
- Store Keeping reads the existing Customer Store ledger, balances and recent movements, subject to the account's Store permission.
- BELM Admin and BELM Technician dashboards are unchanged.
