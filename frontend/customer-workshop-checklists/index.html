Run a machine Check Up

Checklist templates are controlled centrally by BELM System Settings so every workshop uses the approved inspection structure. Customer users can run active checklists and keep their own machine reports, but cannot change the master template.

Customer data stays private: completing a checklist creates a report for your company and machine. Existing checklist history is never overwritten by template updates.
1. Select machineOpen your company machine list.
2. Choose Check UpUse the active checklist assigned to that machine category.
3. Save reportView, print or download the completed report from your records.
