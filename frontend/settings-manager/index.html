Backup

Free Render databases have no automatic backups. Download a full copy of your data periodically and keep it somewhere safe (your computer, Google Drive, email to yourself).

Security PINs

Change the PIN required before confirming edits, or before deleting/clearing records. If you've forgotten the current PIN, just set a new one below — your own login already confirms you're a Super Admin.

Danger Zone — Reset Database

Only for use while still testing/building the portal. Pick one category to clear just that area — the rest stays untouched. This cannot be undone — download a backup first.
